3. 系统壁纸修改前已持久化恢复记录；模拟重启后可恢复。
4. 调整设置始终使用原图，避免把黑边反复叠加。
5. 更改范围时恢复被排除的外接屏幕。

12. 分辨率变更触发重新生成；应用失败不会报告该屏幕已成功应用。
13. 硬件安全区、Retina 倍率与显示范围判断。
14. 壁纸填充、适合、拉伸和居中的布局。

## 验证边界

本次没有安装或常驻运行应用，也没有替换成员的实际壁纸。`--diagnostics` 只读；界面截图是应用自身离屏渲染，未截取成员桌面。

因此，“通过”不代表已完成系统菜单栏最终颜色的目测验收。真实 NSWorkspace 写入、鼠标交互、真实多 Space 切换、睡眠恢复及显示器热插拔仍需使用者验收；相应状态逻辑已使用模拟接口检查。附带 `--smoke-test <恢复记录目录>` 可显式测试真实壁纸应用/恢复，运行前请阅读 README。

macOS 13–15 和后续芯片没有实机测试，仅指定 macOS 13 部署目标并按公开 API 编译。Developer ID 签名、公证和 App Store 分发未执行。

## 建议验收

- 使用静态壁纸，打开开关；查看黑边是否覆盖整个菜单栏背景、文字按钮是否清晰可用。
- macOS Tahoe 如菜单栏仍发灰，检查“系统设置 → 菜单栏 → 显示菜单栏背景”。此选项决定显示壁纸还是系统背景，参见 [Apple 说明](https://support.apple.com/en-mide/guide/mac-help/-mchlad96d366/mac)。应用不会替用户改这项系统设置。
- 切换范围、圆角、额外高度，检查外接屏和内置屏各自结果。
- 切换到其他桌面后检查应用；关闭效果，再依次切回处理过的桌面检查恢复。
- 恢复并退出后，检查原壁纸图片和显示方式；动态/视频壁纸如需动画，回到系统设置重新选择。
